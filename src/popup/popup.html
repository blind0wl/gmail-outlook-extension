Where do I find the client ID?
  1. Open Google Cloud Console, Credentials (create a project first if you have none).
  2. Click Create Credentials, then OAuth client ID, then application type Web application.
  3. Under Authorized redirect URIs, add the redirect URI shown below, copied exactly.
  4. If Google asks for a consent screen, choose External and add your Gmail address under Test users. Request only Gmail read-only access.
  5. Copy the Client ID, not the client secret, into the field above.
