Polish v2

Current popup beside the proposal. Same synthetic mail, both fully interactive.

What changed

  • Cards. Time sits beside the sender; actions float over it on hover or focus, so the footer row is gone. Read mail recedes. Unread dot is larger and aligned to the sender line.
  • Account headers. Address and unread count share a row; provider and check time sit beneath. Counts become pills. Empty accounts read "All caught up."
  • Header and filters. Count pill replaces "(2)". Filters sit in one segmented track. The explainer moves to a quiet footnote.
  • Settings. Account rows have an avatar, a status dot, one relevant action (Sign in or Sign out) and an icon Remove. Themes are tiles. Toggles are switches. Chimes list the address with the provider beneath. Mail checking gains presets that fill the fields; Save stays explicit.
  • Status bar. A slim bar with a hairline replaces the filled block, and lists fade at the bottom edge.

Prototype only. Nothing in src/ has changed. All data is synthetic and provider links are inert.
